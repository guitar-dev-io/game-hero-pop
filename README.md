# ฮีโร่ป๊อป! จับคู่สุดหรรษา 🍬⚔️

เกมจับคู่ 3 (match‑3) บนเว็บ เล่นได้ทั้งมือถือและคอม พร้อมตารางคะแนนออนไลน์
ตัวละครทั้งหมดออกแบบขึ้นใหม่ (ได้แรงบันดาลใจจากมินิเกมจับคู่ฮีโร่)

## ฟีเจอร์
- ลูกอมฮีโร่ 4 ตัว (อควา • ลูน่า • โซล • นิกซ์) อัปเกรดเป็น Lv.2 / Lv.3 พร้อมสกิลเฉพาะตัว
- **ฉากสกิล (cut‑in):** ฮีโร่โผล่มาจากด้านข้าง เหวี่ยงอาวุธฟันกระดาน ก่อนปล่อยสกิล (ปิดได้ที่เมนู)
- **สุดยอดคอมโบ:** สลับลูกอมพิเศษ 2 ลูกเข้าหากัน = ระเบิดกากบาท 3 แถว / Lv.3+Lv.3 = ล้างทั้งกระดาน
- **โหมด FEVER:** เติมเกจจนเต็ม → คะแนน x2 นาน 8 วิ
- สิ่งกีดขวาง: จอมมารเงา (บอส), โกเลมเพลิง, โกเลมน้ำแข็ง, กิ้งก่าแสง, ก้อนหิน — ขยับเต้นตลอดเวลา บอสเลือดน้อยจะเข้าโหมดคลั่ง
- **มอนสเตอร์บุกเป็นระลอก:** ทุกด่านมีตารางบุกของตัวเอง มีไซเรนเตือน แล้วมอนสเตอร์กระโดดลงกระดาน (เวลาหยุดระหว่างฉาก) บทที่ 4–5 จอมมารบุกเข้ามากลางเกม
- ไอเทม: สายฟ้าเสริมพลัง, นาฬิกาล้างสี, ระเบิดพลังงาน
- อนุภาค, จอสั่น, แบนเนอร์คอมโบ, นับถอยหลัง, คำใบ้เมื่อนิ่งนาน, เสียงเอฟเฟกต์
- **กระดานหลายขนาดแบบต้นฉบับ:** สี่เหลี่ยม 8×7, รูปเพชร 9×9, กากบาท 8×7, แบบแคบ 6×8 พร้อมลังไม้และพุ่มหญ้าที่อยู่กับที่ (ลูกอมตกผ่านไม่ได้จนกว่าจะทุบ)
- **มอนสเตอร์ขนาดใหญ่ 2x2:** โกเลมเพลิง, โกเลมน้ำแข็ง และจอมมารเงา มีป้าย HP
- **คอมโบต่อเนื่อง:** ทำลายลูกอมต่อเนื่องภายใน 3 วิ คอมโบนับขึ้นเรื่อยๆ คูณคะแนนสูงสุด x3 (คอมโบ 120) และคอมโบ 40+ สนามลุกเป็นไฟ
- **ฮีโร่ประจำสนาม:** ฮีโร่ยืนข้างกระดาน เปลี่ยนตัวตามสกิลที่เพิ่งใช้ และเหวี่ยงอาวุธ
- **ถาดมอนสเตอร์ + ลูกแก้ว:** เห็นล่วงหน้าว่ามอนสเตอร์ระลอกไหนจะบุก ลูกแก้วเต็มเมื่อไหร่ก็บุก
- **หน้าสรุปผล:** คะแนนตัวใหญ่, ป้ายสถิติใหม่, คอมโบสูงสุด, อันดับ, ปุ่มแชร์/ยืนยัน/ท้าทายด่านถัดไป
- **ด่านโบนัส:** ผ่านครบ 4 ด่านของแต่ละบทจะปลดล็อกด่านโบนัส กระดานรูปเพชรอัดแน่นด้วยลังไม้ เวลา 10 วิ เริ่มด้วยลูกอมโซลพิเศษรอบขอบ (เพิ่มเวลาได้สูงสุด +10 วิ)
- **เพชร 💎:** โผล่มากับลูกอมที่ตกลงมาเป็นครั้งคราว (ด่านโบนัสบ่อยกว่า) ทำลายลูกอมข้างๆ เพื่อเก็บ ได้คะแนน 1,000 และเหรียญ +3
- **แผนที่ด่าน:** 5 บท (I–V) บทละ 4 ด่าน รวม 20 ด่าน + ด่านสุดท้าย ∞ (ปลดล็อกหลังผ่าน 5-4) พร้อมรูปปั้นทองคำ
- **กล่องสมบัติ:** ผ่านด่านครั้งแรกได้กล่อง (ด่านที่ 4 ของแต่ละบทได้กล่องใหญ่) ข้างในมีเหรียญและไอเทม
- **ภารกิจท้าทาย:** ภารกิจรายวัน, ภารกิจรอบนี้ (สะสมดาว/ผ่านด่าน/ปราบบอส) และร้านแลกของด้วยเหรียญ
- ไอเทมฟรีด่านละ 1 ชิ้นต่อชนิด + ใช้ของในกระเป๋าเพิ่มได้
- ตารางคะแนน 10 อันดับแรกแยกทุกด่าน

## การคิดคะแนน (ใช้กติกาเดียวกันทั้งเกม)
- ลูกอม 100 (ลูกอมพิเศษ 200) • สร้าง Lv.2/Lv.3 = 500/750 • ปราบสิ่งกีดขวางได้ตามที่กำหนด
- ทุกแหล่งคะแนนคูณด้วยคอมโบต่อเนื่อง (สูงสุด x3) และ FEVER x2
- สิ่งกีดขวางเสีย HP ได้สูงสุด 2 ต่อการแตก 1 รอบ (บอสไม่ตายเร็วเกินไป)
- เวลาหยุดเดินระหว่างฉากสกิล • เวลาโบนัสรวมสูงสุด +20 วิ ต่อด่าน
- เป้าหมาย 1 ดาวตั้งแยกตามรูปกระดานของแต่ละด่าน (18,000–120,000) บทที่ 4–5 ด่านละ 90 วิ (⭐⭐ = 1.5 เท่า, ⭐⭐⭐ = 2 เท่า)

## หน้าตา
- ฉากลานประลองซากหินพร้อมม่าน, ป้ายเวลา/คะแนนแบบหกเหลี่ยม, ฮีโร่มุมซ้ายล่าง, ไอเทมปุ่มกลมด้านขวา, ถาดมอนสเตอร์ใต้กระดาน, ลูกแก้วมุมขวาล่าง
- กระดานช่องสีน้ำตาลในกรอบสีครีม • หน้าสรุปผลเต็มจอ


## 🚀 Deploy ขึ้น Cloudflare (Workers + D1)

### วิธี A — จากเครื่องตัวเอง
```bash
npm install
npx wrangler login      # ล็อกอินบัญชี Cloudflare (เปิดเบราว์เซอร์)
npm run deploy          # สร้าง D1 + ตาราง แล้ว deploy
```
เสร็จแล้วจะได้ลิงก์ `https://game-hero-pop.<ชื่อบัญชี>.workers.dev`

### วิธี B — อัตโนมัติด้วย GitHub Actions (push แล้วขึ้นเว็บเอง)
1. Cloudflare Dashboard → **My Profile → API Tokens → Create Token** → ใช้เทมเพลต **Edit Cloudflare Workers**
   แล้วเพิ่มสิทธิ์ **Account → D1 → Edit**
2. คัดลอก **Account ID** (หน้า Workers & Pages ด้านขวา)
3. GitHub repo → **Settings → Secrets and variables → Actions → New repository secret**
   - `CLOUDFLARE_API_TOKEN` = token จากข้อ 1
   - `CLOUDFLARE_ACCOUNT_ID` = Account ID จากข้อ 2
4. Push เข้า `main` (หรือกด **Actions → Deploy to Cloudflare → Run workflow**)

workflow จะสร้างฐานข้อมูล `hero-pop-scores` ให้เองถ้ายังไม่มี (ใช้ซ้ำได้ ไม่ลบคะแนนเดิม)

> อยากใช้โดเมนตัวเอง: Workers & Pages → game-hero-pop → Settings → Domains & Routes → Add Custom Domain

### ทดสอบบนเครื่องแบบ Cloudflare
```bash
npm run dev             # http://localhost:8787 (ใช้ D1 จำลองในเครื่อง)
```

## 🏠 รันเป็นเซิร์ฟเวอร์เอง (Node.js, ไม่ต้องใช้ Cloudflare)
```bash
npm run serve           # หรือ node server/server.cjs
```
เปิด `http://localhost:3000` — เพื่อนใน Wi‑Fi เดียวกันใช้ลิงก์ IP ที่ขึ้นใน Terminal
คะแนนเก็บใน `server/scores.json` • เปลี่ยนพอร์ต: `PORT=8080 npm run serve`

## 📄 เปิดไฟล์ตรงๆ
เปิด `public/index.html` ในเบราว์เซอร์ก็เล่นได้ทันที (ตารางคะแนนจะเก็บแค่ในเครื่อง)

## API
| Method | Path | รายละเอียด |
|---|---|---|
| GET | `/api/scores?stage=0..25` | 10 อันดับแรกของด่าน (0–19 = ด่าน 1-1 ถึง 5-4, 20 = ด่านสุดท้าย, 21–25 = ด่านโบนัสบท 1–5) |
| POST | `/api/scores` | `{ "name", "stage", "score", "stars" }` → `{ "ok": true, "rank": n }` |

กันสแปม 20 ครั้ง/นาที ต่อ IP (เก็บเป็นค่าแฮช ไม่เก็บ IP จริง)
